# GPT-Image 2.0 Prompt — Stooges Ezine Page 1 of 4

Generate **Page 1 of 4** of a portrait-oriented developer ezine for a CLI tool called **Stooges**.

## Format

- Portrait page layout
- Suitable for print and screen reading
- High-resolution poster/ezine page
- Single finished page, not a mockup on a desk
- No browser chrome, no UI frame, no watermark

## Art Direction

Create a dramatic vintage silent-film title card / old playbill page. The page should look like an early cinema artifact: theatrical, monochrome, slightly worn, high contrast, and elegant.

Use cream/off-white ink on a black or near-black background. Add subtle film grain, a soft vignette around the edges, and optional vertical film-strip sprocket borders on the left and right.

The design should feel like:

- old Hollywood opening credits
- vaudeville handbill typography
- silent-film intertitle card
- developer tool announcement

It should **not** look like a modern SaaS landing page.

## Palette

Use only this approximate palette:

- true black: `#0a0a0a`
- near black: `#1a1a1a`
- dark gray: `#2a2a2a`
- mid gray: `#666666`
- light gray: `#b0b0b0`
- cream: `#e8e0d0`
- off-white: `#f0ead6`
- warm white: `#f5f1e8`

No bright colors. No neon. No gradients except subtle vignette/shadowing.

## Typography

Use typography that resembles:

- Main title: high-contrast old theatre poster serif, like Playfair Display / vintage movie lettering
- Small labels: engraved small caps / playbill lettering
- Captions: typewriter or old monospace style

Use uppercase letter spacing for small labels.

## Required Text

Place all text carefully and make it legible.

Top small line:

`SCOTT WATERMASYSK PRESENTS`

Main title, very large:

`STOOGES`

Subtitle bar, cream rectangle with black type:

`GIT WORKSPACES, THE SMART WAY`

Tagline:

`Multiple independent copies of your repository — with near-zero disk overhead.`

Punchline:

`No stashing. No conflicts. No nonsense.`

Cast label:

`STARRING`

Three cast cameos:

- `Larry` — `Workspace One`
- `Curly` — `Workspace Two`
- `Moe` — `Workspace Three`

Footer:

`Page 1 of 4 · stooges.dev`

## Composition

Top third:

- Center `SCOTT WATERMASYSK PRESENTS` near the top.
- Below it, huge centered title `STOOGES`.
- Add a subtle drop shadow or ink impression effect to the title.
- Put `GIT WORKSPACES, THE SMART WAY` inside a horizontal cream subtitle placard under the title.

Middle:

- Place the tagline below the subtitle bar.
- Place the punchline below the tagline, slightly more emphatic.
- Add an ornamental divider: `✥ ✥ ✥`.

Lower middle:

- Add the label `STARRING`.
- Show three circular grayscale cameo portraits or simple vintage silhouettes in a row.
- Label them:
  - Larry / Workspace One
  - Curly / Workspace Two
  - Moe / Workspace Three
- The cameos should represent workspace characters, not photo-real people.

Bottom:

- Add a small film-credit style footer: `Page 1 of 4 · stooges.dev`.

## Decorative Details

Include some of these if space allows:

- thin double-line border around the page
- inset playbill border
- film sprocket strips on left and right
- small ornamental diamonds or stars
- aged paper/film grain texture
- slight misregistration or worn ink edges

Keep decoration secondary to readability.

## Negative Instructions

Do not include:

- long install URLs
- GitHub raw URLs
- QR codes
- screenshots of code editors
- modern UI dashboards
- bright color accents
- emoji
- photorealistic celebrities
- extra text beyond the required copy
- distorted or misspelled text

The final image should look like the opening page of a polished four-page printed ezine for Stooges.
